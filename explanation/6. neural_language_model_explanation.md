# Complete Explanation: NeuralLanguageModel Class

## Overview

The `NeuralLanguageModel` class is a wrapper around a trained Transformer model that provides language modeling functionality. It takes a context string and predicts the probability distribution over the next character, or scores entire sequences of characters.

---

## Class Structure

```python
class NeuralLanguageModel(LanguageModel):
    def __init__(self, transformer_model, vocab_index):
        # Initialization

    def get_next_char_log_probs(self, context):
        # Predict next character probabilities

    def get_log_prob_sequence(self, next_chars, context):
        # Score a sequence of characters
```

---

## Initialization (Lines 54-57)

```python
def __init__(self, transformer_model, vocab_index):
    self.model = transformer_model
    self.vocab_index = vocab_index
    self.device = next(self.model.parameters()).device
```

### Input Parameters

1. **`transformer_model`**: A trained `Transformer` instance

   - Already trained on text data
   - Can predict character probabilities
   - Has `use_causal_mask=True` (autoregressive)

2. **`vocab_index`**: An `Indexer` object
   - Maps characters to integer indices (0-26)
   - Same vocabulary as training: 27 characters (a-z + space)

### What Gets Stored

1. **`self.model`**: The trained transformer model
2. **`self.vocab_index`**: Character-to-index mapping
3. **`self.device`**: Device where model parameters are (CPU or GPU)
   - Extracted from model parameters automatically
   - Ensures input tensors go to the same device

### Example

```python
# After training
trained_transformer = Transformer(...)  # Trained model
vocab_index = Indexer()  # Character mappings

# Create NeuralLanguageModel
lm = NeuralLanguageModel(trained_transformer, vocab_index)
# Now can use lm.get_next_char_log_probs() and lm.get_log_prob_sequence()
```

## Method 1: `get_next_char_log_probs(context)` (Lines 59-77)

### Purpose

Given a context string, returns log probabilities for all possible next characters.

### Input

```python
context: str  # The context string (e.g., "hello worl")
```

### Output

```python
np.ndarray  # Shape: [27] - log probabilities for all 27 characters
```

### Step-by-Step Processing

#### Step 1: Set Model to Evaluation Mode (Line 60)

```python
self.model.eval()
```

**What this does:**

- Disables dropout layers (for deterministic inference)
- Turns off batch normalization updates
- Ensures consistent predictions

**Why needed:**

- During training: Dropout randomly zeros some activations (prevents overfitting)
- During inference: We want deterministic predictions (no randomness)

#### Step 2: Convert Context to Indices (Lines 62-65)

```python
if len(context) == 0:
    context_idxs = [0]  # pick first vocab index as placeholder
else:
    context_idxs = [self.vocab_index.index_of(c) for c in context]
```

**What this does:**

- Converts each character in context to its integer index
- Handles empty context (uses index 0 as placeholder)

**Example:**

```python
# Context: "hello worl"
context_idxs = [7, 4, 11, 11, 14, 26, 22, 14, 17, 11]
# h=7, e=4, l=11, l=11, o=14, space=26, w=22, o=14, r=17, l=11

# Empty context:
context = ""
context_idxs = [0]  # Placeholder
```

**Shape:** `[len(context)]` or `[1]` if empty

#### Step 3: Create Input Tensor (Lines 67-69)

```python
input_tensor = torch.tensor(
    context_idxs, dtype=torch.long, device=self.device
)  # (seq_len,)
```

**What this does:**

- Converts list of indices to PyTorch tensor
- Sets dtype to `long` (required for embedding lookup)
- Moves to same device as model (CPU or GPU)

**Example:**

```python
# context_idxs = [7, 4, 11, 11, 14, 26, 22, 14, 17, 11]
input_tensor = torch.tensor([7, 4, 11, 11, 14, 26, 22, 14, 17, 11],
                            dtype=torch.long, device='cpu')
# Shape: [10]
```

#### Step 4: Forward Pass Through Transformer (Lines 71-74)

```python
with torch.no_grad():
    log_probs, _ = self.model(input_tensor)
    # log_probs: (seq_len, vocab_size) when input is 1D
```

**What this does:**

1. **`torch.no_grad()`**: Disables gradient computation (faster, less memory)
2. **`self.model(input_tensor)`**: Forward pass through transformer
3. **Returns**: `(log_probs, attention_maps)`
   - `log_probs`: `[seq_len, vocab_size]` = `[10, 27]`
   - `attention_maps`: List of attention matrices (ignored with `_`)

**What happens inside transformer:**

```
Input: [10] (indices)
  ↓
Token Embedding: [10] → [10, 128]
  ↓
Positional Encoding: [10, 128] → [10, 128]
  ↓
Transformer Layers: [10, 128] → [10, 128]
  ↓
Output Layer: [10, 128] → [10, 27]
  ↓
Log Softmax: [10, 27] → [10, 27]
  ↓
Output: [10, 27] (log probabilities for each position)
```

**Example output:**

```python
log_probs = [
    [-3.2, -2.1, -4.5, ..., -5.1],  # Position 0 ('h') - probs for next char
    [-2.8, -3.4, -4.2, ..., -4.9],  # Position 1 ('e') - probs for next char
    [-3.1, -2.9, -4.1, ..., -5.0],  # Position 2 ('l') - probs for next char
    ...
    [-1.5, -4.2, -5.3, ..., -6.1],  # Position 9 ('l') - probs for next char
]
# Shape: [10, 27]
# Each row: log probabilities for all 27 characters at that position
```

#### Step 5: Extract Last Position's Probabilities (Line 76)

```python
next_logits = log_probs[-1, :]
```

**What this does:**

- Takes the **last row** of log_probs (last position in context)
- This represents probabilities for the **next character** after the entire context

**Why the last position?**

- Position 0: Predicts character after "h"
- Position 1: Predicts character after "he"
- Position 2: Predicts character after "hel"
- ...
- **Position 9 (last)**: Predicts character after "hello worl" ← **This is what we want!**

**Example:**

```python
# log_probs shape: [10, 27]
# log_probs[-1, :] takes row 9 (last position)
next_logits = [-1.5, -4.2, -5.3, -3.8, ..., -6.1]
# Shape: [27]
# These are log probabilities for next character after "hello worl"
```

**Visual representation:**

```
log_probs matrix:
        Class 0  Class 1  Class 2  ...  Class 26
Pos 0:  [-3.2,   -2.1,   -4.5,    ..., -5.1  ]
Pos 1:  [-2.8,   -3.4,   -4.2,    ..., -4.9  ]
...
Pos 9:  [-1.5,   -4.2,   -5.3,    ..., -6.1  ]  ← Take this row!
        ↑
    next_logits = log_probs[-1, :]
```

#### Step 6: Convert to NumPy (Line 77)

```python
return next_logits.cpu().numpy()
```

**What this does:**

- Moves tensor from GPU to CPU (if on GPU)
- Converts to NumPy array
- Returns as `np.ndarray` of shape `[27]`

**Final output:**

```python
# Context: "hello worl"
# Returns:
array([-1.5, -4.2, -5.3, -3.8, -2.9, ..., -6.1])  # 27 values
# Shape: [27]
# Each value: log probability of that character being next
```

## Method 2: `get_log_prob_sequence(next_chars, context)` (Lines 79-88)

### Purpose

Given a context and a sequence of next characters, computes the total log probability of that sequence.

### Input

```python
next_chars: str  # Sequence of characters to score (e.g., "d")
context: str     # Context string (e.g., "hello worl")
```

### Output

```python
float  # Total log probability of the sequence
```

### Mathematical Formula

```
log P(nc1, nc2, nc3, ... | context) =
    log P(nc1 | context) +
    log P(nc2 | context, nc1) +
    log P(nc3 | context, nc1, nc2) +
    ...
```

**Key insight:** Probability of a sequence = product of individual character probabilities
**In log space:** Sum of individual log probabilities

### Step-by-Step Processing

#### Step 1: Set Model to Evaluation Mode (Line 80)

```python
self.model.eval()
```

Same as before - ensures deterministic inference.

#### Step 2: Initialize Accumulator (Lines 81-82)

```python
total_log_prob = 0.0
cur_context = context
```

**What this does:**

- `total_log_prob`: Accumulates log probabilities
- `cur_context`: Current context (grows as we process each character)

#### Step 3: Process Each Character (Lines 83-87)

```python
for ch in next_chars:
    log_probs = self.get_next_char_log_probs(cur_context)
    ch_idx = self.vocab_index.index_of(ch)
    total_log_prob += log_probs[ch_idx]
    cur_context += ch
```

**What this does for each character:**

1. **Get probabilities for current context:**

   ```python
   log_probs = self.get_next_char_log_probs(cur_context)
   # Returns [27] log probabilities
   ```

2. **Find index of current character:**

   ```python
   ch_idx = self.vocab_index.index_of(ch)
   # e.g., 'd' → 3
   ```

3. **Add that character's log probability:**

   ```python
   total_log_prob += log_probs[ch_idx]
   # Accumulate: total = total + log P(ch | cur_context)
   ```

4. **Update context:**
   ```python
   cur_context += ch
   # Add character to context for next iteration
   ```

#### Step 4: Return Total (Line 88)

```python
return float(total_log_prob)
```

Returns the accumulated log probability as a float.

## Complete Example: `get_log_prob_sequence`

### Input

```python
context = "hello worl"
next_chars = "d"
```

### Processing Steps

**Iteration 1 (ch = 'd'):**

1. **Get probabilities:**

   ```python
   cur_context = "hello worl"
   log_probs = get_next_char_log_probs("hello worl")
   # Returns: [-1.5, -4.2, -5.3, -2.9, ..., -6.1]
   #          [  a,    b,    c,    d,  ...,   space]
   ```

2. **Find index:**

   ```python
   ch_idx = vocab_index.index_of('d')  # = 3
   ```

3. **Add probability:**

   ```python
   total_log_prob += log_probs[3]  # = -2.9
   total_log_prob = -2.9
   ```

4. **Update context:**
   ```python
   cur_context = "hello worl" + "d" = "hello world"
   ```

**Return:**

```python
return -2.9  # Log probability of "d" given "hello worl"
```

## Why This Design?

### Autoregressive Property

The model processes characters **one at a time**:

```
P("world" | "hello ") =
    P('w' | "hello ") ×
    P('o' | "hello w") ×
    P('r' | "hello wo") ×
    P('l' | "hello wor") ×
    P('d' | "hello worl")
```

**In log space:**

```
log P("world" | "hello ") =
    log P('w' | "hello ") +
    log P('o' | "hello w") +
    log P('r' | "hello wo") +
    log P('l' | "hello wor") +
    log P('d' | "hello worl")
```

**This matches how the model was trained:**

- Training: Predict character at position i+1 given characters 0 to i
- Inference: Same pattern - predict next character given context

### Why Take Last Position?

In `get_next_char_log_probs()`:

```python
next_logits = log_probs[-1, :]
```

**The transformer outputs probabilities for ALL positions:**

- Position 0: P(next | "h")
- Position 1: P(next | "he")
- Position 2: P(next | "hel")
- ...
- Position 9: P(next | "hello worl") ← **This is what we want!**

**We only care about the last position** because:

- It has seen the entire context
- It represents P(next_char | full_context)
- Earlier positions have less context

## Key Differences from Letter-Counting

| Aspect           | Letter-Counting                     | Language Model                                   |
| ---------------- | ----------------------------------- | ------------------------------------------------ |
| **Input**        | Full sequence (20 chars)            | Context string (variable length)                 |
| **Output**       | Classification at each position     | Next character probabilities                     |
| **Task**         | Count occurrences                   | Predict next character                           |
| **Model output** | `[20, 3]` (20 positions, 3 classes) | `[seq_len, 27]` (variable length, 27 chars)      |
| **Usage**        | Process entire sequence at once     | Process one character at a time (autoregressive) |
| **Causal mask**  | Optional (BEFORE task)              | Required (always autoregressive)                 |

## Summary

### `NeuralLanguageModel` Class

**Initialization:**

- Stores trained transformer model
- Stores vocabulary indexer
- Detects device (CPU/GPU)

**`get_next_char_log_probs(context)`:**

- Input: Context string
- Processing: Convert to indices → Transformer forward → Extract last position
- Output: `[27]` log probabilities for next character

**`get_log_prob_sequence(next_chars, context)`:**

- Input: Context string + sequence to score
- Processing: For each character, get probabilities and accumulate
- Output: Total log probability of the sequence

**Key insight:**

- Model is **autoregressive**: Predicts one character at a time
- Each prediction uses the full context seen so far
- Sequence probability = sum of individual character log probabilities

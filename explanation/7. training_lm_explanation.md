# Complete Explanation: Training Language Model (train_lm)

## Overview

The `train_lm()` function trains a Transformer model to predict the next character given a context. This is an autoregressive language modeling task where the model learns character-level patterns from text data.

---



### Step 5: Loss, Optimizer, Scheduler (Lines 185-191)

```python
criterion = nn.NLLLoss()  # Negative Log Likelihood Loss
optimizer = optim.Adam(model.parameters(), lr=1e-3, betas=(0.9, 0.98), weight_decay=1e-4)
scheduler = optim.lr_scheduler.ReduceLROnPlateau(
    optimizer, mode="min", factor=0.6, patience=1, min_lr=1e-5

```

**Loss function:**
- `NLLLoss`: Works with log probabilities
- Expects: `log_probs` (from model) and `targets` (ground truth indices)

**Optimizer:**
- `Adam` with learning rate 1e-3
- `betas=(0.9, 0.98)`: Momentum parameters
- `weight_decay=1e-4`: L2 regularization

**Scheduler:**
- `ReduceLROnPlateau`: Reduces learning rate when dev loss plateaus
- `factor=0.6`: Multiply LR by 0.6 when reducing
- `patience=1`: Wait 1 epoch before reducing
- `min_lr=1e-5`: Minimum learning rate

## Training Loop: How Each Epoch Runs

### Epoch Structure (Lines 199-255)

Each epoch consists of:
1. **Shuffle training data**
2. **Process in batches**
3. **Compute loss and update weights**
4. **Evaluate on dev set**
5. **Adjust learning rate**

---

### Step 1: Initialize Epoch (Lines 200-201)

```python
epoch_loss = 0.0
t0 = time.time()
```

**What this does:**
- Resets loss accumulator
- Records start time for timing

---

### Step 2: Shuffle Training Data (Lines 203-205)

```python
indices = torch.randperm(len(train_inputs))
train_inputs_shuffled = train_inputs[indices]
train_targets_shuffled = train_targets[indices]
```

**What this does:**
- Creates random permutation of chunk indices
- Shuffles both inputs and targets together (maintains pairing)
- Ensures model sees data in different order each epoch

**Why shuffle:**
- Prevents model from learning order-dependent patterns
- Improves generalization
- Standard practice in training

**Example:**
```python
# Original order: [0, 1, 2, 3, ..., 999]
# After shuffle:   [342, 12, 789, 45, ..., 123]
# Both inputs and targets shuffled the same way
```

---

### Step 3: Process in Batches (Lines 207-226)

```python
chunk_count = 0
total_chunks = len(train_inputs_shuffled)
chunk_batch_size = 10

for i in range(0, total_chunks, chunk_batch_size):
    batch_end = min(i + chunk_batch_size, total_chunks)
    inp = train_inputs_shuffled[i:batch_end].to(device)
    tgt = train_targets_shuffled[i:batch_end].to(device)
```

**What this does:**
- Processes chunks in batches of 10
- Moves data to device (CPU/GPU)
- Creates mini-batches for efficient training

**Batch structure:**
```python
# If we have 1000 chunks and batch_size=10:
# Batch 0: chunks 0-9
# Batch 1: chunks 10-19
# Batch 2: chunks 20-29
# ...
# Batch 99: chunks 990-999

# Each batch:
inp.shape = [10, 256]  # 10 chunks, each 256 chars
tgt.shape = [10, 256]  # 10 targets, each 256 chars
```

---

### Step 4: Forward Pass (Line 217)

```python
optimizer.zero_grad()
log_probs, _ = model(inp)
```

**What this does:**
1. **`optimizer.zero_grad()`**: Clears previous gradients
2. **`model(inp)`**: Forward pass through transformer

**Forward pass flow:**
```
Input: [10, 256] (batch, seq_len)
  ↓
Token Embedding: [10, 256] → [10, 256, 128]
  ↓
Positional Encoding: [10, 256, 128] → [10, 256, 128]
  ↓
Transformer Layers (3 layers): [10, 256, 128] → [10, 256, 128]
  ↓
Output Layer: [10, 256, 128] → [10, 256, 27]
  ↓
Log Softmax: [10, 256, 27] → [10, 256, 27]
  ↓
Output: [10, 256, 27] (log probabilities)
```

**What `log_probs` contains:**
- Shape: `[batch_size, seq_len, vocab_size]` = `[10, 256, 27]`
- `log_probs[b, i, j]`: Log probability of character j at position i in batch b
- Each position has probabilities for all 27 characters

---

### Step 5: Compute Loss (Line 218)

```python
loss = criterion(log_probs.view(-1, vocab_size), tgt.view(-1))
```

**What this does:**
1. **Reshape log_probs**: `[10, 256, 27]` → `[2560, 27]`
   - Flattens batch and sequence dimensions
   - Each row: log probabilities for one position

2. **Reshape targets**: `[10, 256]` → `[2560]`
   - Flattens to 1D
   - Each value: target character index

3. **Compute NLLLoss**:
   - For each position, takes log probability of the target character
   - Averages over all positions
   - Returns negative value (we want to minimize)

**Mathematical formula:**
```
loss = - (1/N) × Σ log P(target[i] | input[0:i+1])
```

Where:
- N = total number of positions (batch_size × seq_len)
- target[i] = ground truth character at position i
- input[0:i+1] = context up to position i

**Example:**
```python
# Batch 0, Position 0:
# Input: "h" (index 7)
# Target: "e" (index 4)
# log_probs[0, 0, 4] = log P('e' | "h") = -2.3

# Batch 0, Position 1:
# Input: "he" (indices 7, 4)
# Target: "l" (index 11)
# log_probs[0, 1, 11] = log P('l' | "he") = -1.8

# Loss averages over all 2560 positions
loss = -average of all log probabilities
```

---

### Step 6: Backward Pass and Update (Lines 219-221)

```python
loss.backward()
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
optimizer.step()
```

**What this does:**
1. **`loss.backward()`**: Computes gradients
   - Backpropagates through entire network
   - Computes gradient for each parameter

2. **`clip_grad_norm_()`**: Gradient clipping
   - Clips gradient norm to max 1.0
   - Prevents exploding gradients
   - Stabilizes training

3. **`optimizer.step()`**: Update weights
   - Updates all model parameters using gradients
   - Uses Adam optimizer algorithm

---

### Step 7: Accumulate Loss (Lines 223-226)

```python
epoch_loss += loss.item()
chunk_count += batch_end - i
if chunk_count % (chunk_batch_size * 300) == 0:
    print(f"  Chunk {chunk_count}/{total_chunks} - Loss: {loss.item():.4f}")
```

**What this does:**
- Accumulates loss for epoch average
- Tracks progress
- Prints progress every 300 batches

---

### Step 8: Compute Epoch Average Loss (Lines 228-231)

```python
t1 = time.time()
num_batches = (total_chunks + chunk_batch_size - 1) // chunk_batch_size
avg_loss = epoch_loss / num_batches if num_batches > 0 else epoch_loss
print(f"Epoch {epoch + 1}/{num_epochs} - Loss: {avg_loss:.4f}")
```

**What this does:**
- Computes average loss over all batches
- Prints epoch summary
- Records time taken

**Example output:**
```
Epoch 1/6 - Loss: 2.3456
```

---

### Step 9: Dev Evaluation (Lines 233-255)

```python
if (epoch + 1) % 1 == 0 and dev_sample_size > 0:
    model.eval()
    with torch.no_grad():
        dev_loss = 0.0
        dev_chunks = 0
        dev_batch_size = 8
        for j in range(0, dev_sample_size, dev_batch_size):
            batch_end = min(j + dev_batch_size, dev_sample_size)
            dev_inp = dev_inputs[j:batch_end].to(device)
            dev_tgt = dev_targets[j:batch_end].to(device)
            dev_log_probs, _ = model(dev_inp)
            batch_loss = criterion(
                dev_log_probs.view(-1, vocab_size), dev_tgt.view(-1)
            ).item()
            num_elements = (batch_end - j) * seq_len
            dev_loss += batch_loss * num_elements
            dev_chunks += batch_end - j
        if dev_chunks > 0:
            avg_dev_loss = dev_loss / (dev_chunks * seq_len)
            est_perplexity = np.exp(avg_dev_loss)
            print(f"  Dev Loss: {avg_dev_loss:.4f}")
            scheduler.step(avg_dev_loss)
    model.train()
```

**What this does:**

1. **Set model to eval mode:**
   - `model.eval()`: Disables dropout, batch norm updates

2. **Process dev batches:**
   - Similar to training, but no gradient computation
   - `torch.no_grad()`: Saves memory

3. **Compute dev loss:**
   - Same loss function as training
   - Averages over dev chunks

4. **Compute perplexity:**
   ```python
   est_perplexity = np.exp(avg_dev_loss)
   ```
   - Perplexity = exp(average loss)
   - Lower perplexity = better model

5. **Update learning rate:**
   - `scheduler.step(avg_dev_loss)`: Adjusts LR based on dev loss
   - If loss plateaus, reduces learning rate

6. **Set model back to train mode:**
   - `model.train()`: Re-enables dropout for next epoch

### During Evaluation (lm.py lines 150-152)

After training, the model is evaluated on the full dev set:

#### 1. Log Probability (Line 150)

```python
log_prob = float(lm.get_log_prob_sequence(text, ""))
```

**What this does:**
- Uses `NeuralLanguageModel.get_log_prob_sequence()`
- Computes log probability of entire dev text
- Context starts empty: `""`

**How it works:**
```python
# For text = "hello world"
# Computes:
log_prob = log P("hello world" | "")
         = log P('h' | "") +
           log P('e' | "h") +
           log P('l' | "he") +
           log P('l' | "hel") +
           ... +
           log P('d' | "hello worl")
```

**Result:** Single float value (negative, typically large magnitude)

**Example:**
```python
# Dev text: 10,000 characters
log_prob = -23456.78  # Total log probability
```

---

#### 2. Average Log Probability (Line 151)

```python
avg_log_prob = log_prob / len(text)
```

**What this does:**
- Divides total log probability by text length
- Gives average log probability per character

**Mathematical formula:**
```
avg_log_prob = (1/N) × Σ log P(char[i] | context[0:i])
```

Where N = length of text

**Example:**
```python
log_prob = -23456.78
len(text) = 10000
avg_log_prob = -23456.78 / 10000 = -2.3457
```

**Interpretation:**
- Average log probability per character
- More negative = less confident
- Closer to 0 = more confident

---

#### 3. Perplexity (Line 152)

```python
perplexity = np.exp(-log_prob / len(text))
```

**What this does:**
- Computes perplexity from average log probability
- Formula: `perplexity = exp(-avg_log_prob)`

**Mathematical formula:**
```
perplexity = exp(-avg_log_prob)
           = exp(-log_prob / len(text))
```

**Alternative formula:**
```
perplexity = exp(avg_loss)
```

Where `avg_loss` is the average NLLLoss.

**Example:**
```python
avg_log_prob = -2.3457
perplexity = exp(-(-2.3457)) = exp(2.3457) = 10.44
```

**What perplexity means:**
- **Perplexity = N**: Model is as confused as if choosing uniformly from N options
- **Lower perplexity = better model**
- **Perplexity = 27**: As bad as random guessing (27 characters)
- **Perplexity < 27**: Better than random
- **Perplexity = 1**: Perfect prediction (impossible in practice)

**Interpretation:**
- Perplexity of 10: Model is as uncertain as choosing from 10 equally likely options
- Perplexity of 5: Model is more confident (fewer options)
- Perplexity of 20: Model is less confident (more options)

**Relationship:**
```
perplexity = exp(-avg_log_prob)
           = exp(avg_loss)
           = 1 / (geometric_mean of probabilities)
```

## Key Training Details

### Batch Processing

**Training batches:**
- `chunk_batch_size = 10`: Process 10 chunks at a time
- Each chunk: 256 characters
- Total positions per batch: 10 × 256 = 2,560

**Dev batches:**
- `dev_batch_size = 8`: Process 8 chunks at a time
- Limited to 50 chunks total (faster evaluation)

### Loss Computation

**Training loss:**
```python
loss = NLLLoss(log_probs.view(-1, 27), targets.view(-1))
# Flattens: [10, 256, 27] → [2560, 27]
#           [10, 256]     → [2560]
# Computes loss for each of 2560 positions
```

**Dev loss:**
```python
avg_dev_loss = dev_loss / (dev_chunks * seq_len)
# Weighted average over all dev positions
```

### Learning Rate Scheduling

**ReduceLROnPlateau:**
- Monitors dev loss
- If dev loss doesn't improve for 1 epoch → reduce LR by 0.6
- Continues until `min_lr=1e-5` reached

**Example:**
```
Epoch 1: LR = 1e-3, Dev Loss = 2.12
Epoch 2: LR = 1e-3, Dev Loss = 1.88  (improved, keep LR)
Epoch 3: LR = 1e-3, Dev Loss = 1.89  (no improvement, reduce!)
Epoch 4: LR = 6e-4, Dev Loss = 1.75  (reduced LR, improved)
```

## Summary

### Training Process

1. **Setup**: Create model, optimizer, scheduler
2. **Data**: Prepare chunks with overlap
3. **Epochs**: For each epoch:
   - Shuffle data
   - Process in batches
   - Compute loss and update weights
   - Evaluate on dev set
   - Adjust learning rate
4. **Return**: Trained `NeuralLanguageModel`

### Metrics

- **Training Loss**: Average NLLLoss over training batches
- **Dev Loss**: Average NLLLoss over dev set
- **Perplexity**: `exp(dev_loss)` - measure of model uncertainty
- **Log Probability**: Total log prob of text sequence
- **Avg Log Prob**: Average log prob per character

### Key Features

- **Causal masking**: Always enabled (autoregressive)
- **Multi-head attention**: 4 heads for richer patterns
- **Gradient clipping**: Prevents exploding gradients
- **Learning rate scheduling**: Adapts to training progress
- **Batch processing**: Efficient GPU utilization
